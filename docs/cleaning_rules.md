# 数据清洗与消歧规则
## 一、去重规则
1. 优先依据 DOI 完全匹配去重；
2. 无DOI文献，匹配标题+第一作者+发表年份组合去重；
3. 重复文献仅保留1条原始记录。

## 二、无效文献剔除规则
1. 剔除会议摘要、简讯、广告类非目标文献；
2. 剔除字段大面积缺失（无关键词/参考文献）的文献。

## 三、作者消歧规则
1. 统一姓名格式：名缩写+姓（例：Li J = Jun Li）；
2. 同一作者多写法，建立映射表统一标识。

## 四、机构消歧规则
1. 统一高校、科研机构中英文别名；
2. 合并同一机构不同分部名称。

## 五、版本记录
v1.0：初始清洗规则，用于本次全量数据集处理
