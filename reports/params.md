# 计量分析基线参数文档
## 一、CiteSpace 配置
软件版本：CiteSpace 6.1.R6
1. 时间切片：单年切片，区间 2020–2026
2. 数据阈值：每个切片保留 Top 50 高频条目
3. 网络类型：关键词共现、文献共被引、机构合作网络
4. 聚类算法：Louvain
5. 聚类标准：模块度 Q > 0.3 判定为有效聚类

## 二、VOSviewer 配置
1. 共现最低阈值：频次 ≥3
2. 权重规则：以共现/共被引频次为权重
3. 可视化模式：聚类视图 + 密度视图

## 三、Python 分析参数
1. 共被引矩阵：C = A.T @ A
2. 文献耦合矩阵：B = A @ A.T
3. 相似度算法：余弦相似度
4. 图表输出路径：../outputs/figures
5. 指标表格输出路径：../outputs/tables
