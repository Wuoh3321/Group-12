## 🎯 研究方向
现代医学在疾病诊断、治疗、预后管理、公共卫生等领域不断发展，但仍面临诊断效率不足、影像判读误差、海量医学数据难以挖掘、基层医疗资源不均等现实难题。人工智能凭借大数据分析、深度学习、计算机视觉等技术，逐步成为破解医学痛点的重要手段，AI + 医学也成为全球交叉研究热点。本项目采用文献计量方法，依托 Web of Science/OpenAlex 文献数据，通过发文趋势、网络聚类、共被引分析等手段，系统梳理 AI 在现代医学领域的研究格局、知识基础与发展趋势，明确研究热点与现存空白，为后续相关研究提供参考与借鉴。

---

## 📌 研究目标
本研究采用文献计量学方法，系统分析 AI 在现代医学应用领域的相关文献，梳理领域发展概况、研究热点与合作格局，挖掘知识脉络与前沿方向，为该领域后续研究提供数据参考。

---

## 📊 数据来源
本项目数据主要来源于学术数据库（如 Web of Science / Google Scholar），通过关键词检索获取相关文献。


---

## 🧱 项目结构
data/      存放原始文献数据
config/    存放检索式
src/       存放数据处理与分析代码
outputs/   存放分析结果（图表、网络图等）
reports/   存放分析报告与过程说明
paper/     存放最终论文稿件

## ⚙️ 使用工具

- CiteSpace —— 文献计量分析与可视化  
- VOSviewer —— 关键词共现与网络分析  
- Python —— 数据处理与统计分析  

常用Python库：
- pandas  
- numpy  
- matplotlib  

---

## 🚀 使用方法（可复现说明）

### 1️⃣ 获取数据
将文献数据文件（CSV格式）放入 `data/` 文件夹。

### 2️⃣ 数据处理
运行 `src/` 中的Python脚本进行数据清洗与统计分析。

### 3️⃣ 可视化分析
使用 CiteSpace 或 VOSviewer 对数据进行分析，生成关键词网络图、趋势图等。

### 4️⃣ 输出结果
所有分析结果保存在 `outputs/` 文件夹中。
